# HMPL — Human–Machine Parallel Law

HMPL is a constitutional governance framework for deploying AI in regulated, high‑stakes domains. It enforces **design‑time incapacity**: the Artificial Domain is structurally prevented from internalizing meaning or assuming illegitimate authority.

## What’s inside

- `law/` — the canonical HMPL v1.0 law text
- `implementation/` — engineering implementation guide + reference architecture
- `schemas/` — canonical JSON Schemas (E‑PKT, C‑PACK, S‑SNAP, D‑PKT, H‑PREC, P‑BNDL)
- `cxl/` — Constraint Expression Language (CXL) grammar and checks
- `journals/` — arXiv + journal adaptation drafts
- `governance/` — authority classes, precedent‑to‑policy pipeline, and ledger event specs
- `regulators/` — regulator‑facing memo artifacts
- `whitepapers/` — executive thesis, author note, and rebuttals
- `docs/` — extra notes and clarifications
- `implementation/runtime/hmpl-repo-skeleton/` — runnable TypeScript skeleton (validators, sentinels)

## Quick start

1. Read the law: `law/HMPL_v1.0.md`
2. Build the architecture: `implementation/reference_architecture.md`
3. Gate all Dash traffic with schema validation: `schemas/`
4. Enforce constraints using CXL: `cxl/`
5. Record governance events (hashes/signatures only): `governance/h-ledger/`

## Terminology note

Dubai’s Human–Machine Collaboration (HMC) Icons are a disclosure system for content creation. HMPL is a governance and execution protocol. See `docs/HMPL_vs_Dubai_HMC.md`.
